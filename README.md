# Во сколько обойдётся автомобиль

Интерактивное сравнение полной стоимости владения автомобилями на 3, 5, 8 лет или свой срок. Включает покупку, топливо, обслуживание, страховки, шины, резерв ремонта, перепродажу и необязательный финансовый блок.

**Сайт:** <https://valeter.github.io/auto-tco/>

В сравнении Lada Azimut, Changan CS75 Plus IV, TENET T9, GAC GS8, Haval Jolion, Volga K50, Belgee X70, Lada Granta и настраиваемый «Твой автомобиль». Granta выбрана исходной базой сравнения расходов.

## Как устроен проект

- `dist/` — готовый статический сайт, без сборки и внешних зависимостей.
- `dist/model.mjs` — исходные значения, схемы настроек, миграции сценариев и расчёты.
- `dist/app.mjs` — интерфейс, сохранение сценариев, ссылки и CSV.
- `dist/sources.mjs` — источники и степень подтверждения исходных параметров.
- `dist/audit.html` — проверка данных и ограничения модели.
- `model.test.mjs` — проверки расчётов и обратной совместимости сценариев.
- `ux-qa.mjs` — проверка интерфейса в браузере через Chrome DevTools Protocol.

Данные проверены 22 октября 2026 года. Часть параметров — явно обозначенные допущения; они не обновляются автоматически. Прогноз перепродажи не гарантирует будущую цену сделки. Все вычисления выполняются в браузере.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте <http://127.0.0.1:4173/>. Для запуска сайта Node.js не требуется.

## Проверки

Тесты расчётов требуют Node.js 22 или новее; устанавливать зависимости не нужно:

```sh
npm test
```

Для теста интерфейса запустите локальный сервер и отдельный Chromium-совместимый браузер с `--remote-debugging-port=9223` и временным `--user-data-dir`, затем выполните:

```sh
npm run test:browser
```

Переменные окружения теста:

- `QA_BASE_URL` — адрес тестового сайта с завершающим `/`, по умолчанию `http://127.0.0.1:4173/`.
- `QA_CDP_URL` — адрес браузерного DevTools, по умолчанию `http://127.0.0.1:9223/`.
- `QA_OUTPUT_DIR` — папка снимков экрана; по умолчанию `auto-tco-qa` внутри системной временной папки.

Тест очищает браузерное хранилище тестируемого сайта. Используйте отдельный профиль браузера.

## Публикация

GitHub Pages настроен на GitHub Actions. Workflow `.github/workflows/pages.yml` проверяет расчёты и публикует только содержимое `dist/` после изменений в `main`. В pull request выполняются проверки без публикации. Повторный запуск доступен через Actions → Test and deploy GitHub Pages → Run workflow.

Ресурсы используют относительные пути, поэтому сайт работает под `/auto-tco/`. Сервер, секреты и платные сервисы для приложения не нужны.

## Перенос сценариев со старого адреса

Настройки и именованные сценарии хранятся локально для каждого адреса сайта. GitHub Pages не получает хранилище прежней публикации автоматически.

На старом сайте откройте нужный сценарий и нажмите «Ссылка на сценарий». В полученной ссылке замените часть до `#s=` на `https://valeter.github.io/auto-tco/`, сохранив весь фрагмент `#s=...`. Откройте новый адрес и сохраните сценарий в браузере. Для каждого именованного сценария перенос выполняется отдельно.
